Penjelasan tugas:
Halo, untuk penugasan Week 4 terkait Bootstrap dan Tailwind, kalian diminta membuat sebuah landing page sederhana menggunakan kedua framework tersebut.
Di dalam folder week-4/, buatlah dua folder terpisah, yaitu:
* bootstrap-version/
* tailwind-version/
Masing-masing folder berisi implementasi landing page yang sama, tetapi menggunakan framework CSS sesuai nama foldernya.
Konten landing page bebas, kalian boleh memilih tema apa pun, misalnya landing page produk, layanan digital, aplikasi, portofolio pribadi, atau bisnis. Namun, pastikan landing page memiliki komponen dasar berikut:
* Navbar untuk navigasi.
* Hero section yang berisi judul utama, deskripsi singkat, dan tombol CTA.
* Section konten yang menjelaskan fitur, layanan, atau keunggulan produk.
* Footer yang berisi informasi tambahan atau hak cipta.

Ketentuan pengerjaan:
* Gunakan Bootstrap pada folder bootstrap-version/ dan Tailwind CSS pada folder tailwind-version/.
* Kedua landing page harus memiliki konten dan struktur yang relatif sama agar dapat dibandingkan dari segi implementasi dan penggunaan framework.
* Pastikan tampilan rapi, responsif, dan dapat dibuka melalui browser.
* Kalian diperbolehkan menggunakan aset tambahan seperti gambar, ikon, atau ilustrasi sesuai kebutuhan.

Sederhana saja, tidak perlu yang kompleks, yang penting kalian dapat mengimplementasikan bootstrap dan tailwind ya teman-teman.
